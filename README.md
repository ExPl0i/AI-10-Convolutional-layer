# Свертка и сверточный слой

Занятие курса «Искусственный интеллект» для 10 класса (практическая работа №1, часть 3К). Ученики разбираются, как работает операция свертки, пишут сверточный слой и пулинг на «голых» тензорах, сверяют их с `torch.nn.functional` и смотрят, какие признаки выделяют простые фильтры на настоящей картинке.

## Теория (презентация)

1. **Операция свертки** – ядро скользит по картинке, ядро $[-1, 0, 1]$ ищет границу, фильтры, кросс-корреляция.
2. **Сверточный слой** – размер выхода, каналы, число параметров, три идеи, из-за которых свертка подходит для картинок.
3. **Пулинг и рецептивное поле** – max pooling, рост рецептивного поля, сильные и слабые стороны.
4. **Пишем свертку на Python** – как хранить сверточный слой, план практики.

## Практическая работа

Сквозной пример – картинка $5 \times 5$ с вертикальной границей и ядро $3 \times 3$ со строками $-1, 0, 1$. В конце фильтры применяются к изображению из FashionMNIST.

1. Свертка одной картинки одним ядром.
2. Размер выхода и число параметров.
3. Сверточный слой: пакет, каналы, шаг, дополнение нулями.
4. Max pooling.
5. Сверка с PyTorch.
6. Фильтры на настоящей картинке.

Задания повышенной сложности: свертка через матричное умножение (im2col, `F.unfold`) с замером скорости, рецептивное поле через градиенты.

**Правило работы:** в заданиях К1–К4 внутри своих функций – только срезы тензоров, арифметика, `.sum`, `.amax` и циклы `for`. Готовые `nn.Conv2d`, `F.conv2d`, `F.pad`, `F.max_pool2d`, `unfold` – только в задании К5 (сверка).

## Данные

Для задания К6 нужен FashionMNIST в папке `data`. Скачайте его заранее (в аудитории интернет не нужен):

```python
from torchvision import datasets
datasets.FashionMNIST('data', train=False, download=True)
```
